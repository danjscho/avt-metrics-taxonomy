- **TP.DI-1 / TP.DI-2 (DER, SAA):** Wang et al. inline links duplicate `[Wang-ADS-Eval-2025]` — replace with handle
- **TP.SN-3 (PDSQI-9):** Stetson 2012 inline link is fine as-is (catalogue [PDSQI-9] handle covers the lineage)

**Expected diff size:** small — replacing inline `[Author 20XX](url)` markdown links with `[Handle]` resolution where handles exist, ~5–10 spots.
