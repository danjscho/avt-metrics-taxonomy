# Metric Duplication Review (v3.6 audit, frozen at v3.6 ship date)

This is a research artefact. It does not change any metric, family, or sub-cluster definition. v3.7 will act on findings with explicit user sign-off per pair.

## Methodology

For each of the 20 group files, every within-group metric pair was reviewed against the metric's name, formal definition, dimensions (Pipeline Layer, Assurance Question, Outcome Type), and any existing family / sub-cluster framing. Three classifications:

- **distinct** — different constructs, different data sources, no measurement overlap. Default classification.
- **overlapping** — different views of the same underlying construct OR shared data sources where reporting one would meaningfully inform the other. The relationship may already be acknowledged via a family framing or See-also; if it is, that is recorded.
- **redundant** — same construct measured the same way; one should be merged into or cut in favour of the other.

After the within-group sweep, candidates surfaced were checked for cross-group overlap. The Demographic Equity Disaggregation family (TP.ASR-4 / TP.ASR-5 / TP.CC-9 / IO.FE-2 / IO.FE-4 / IO.FE-5 / PI.E2E-5) is a known cross-cutting family with explicit framing in `_summary.md`; cross-references like that are recorded but not re-flagged as overlap.

Adjacent candidate (lower priority):
4. **HL.HF-1 Edit Rate ↔ HL.HF-11 Inter-Clinician Edit Variance** — v3.4 tightening of HF-1 mandates per-clinician disaggregation, which substantially overlaps HF-11's measurement.
5. **GV.TC-1 Training Completion (M4 module) ↔ GV.TC-3 Refresher & CPD Compliance** — v3.5 tightening makes M4 explicit; question is whether TC-3 is subsumed.
