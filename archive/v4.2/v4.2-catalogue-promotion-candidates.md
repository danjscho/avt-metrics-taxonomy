## How to use this list

Pick this up in a future catalogue-housekeeping release (no specific timing). Decision criteria for promotion:

1. **Multi-use** — if a citation is referenced from multiple metrics, promote (single-source-of-truth principle).
2. **Risk of conflation** — if an inline cite sits next to a catalogue-handled cite and could be mistaken for the same source, promote (Koenecke 2020 is the headline example).
3. **Future load-bearing potential** — if the citation is likely to be cited again in a future release (e.g. M-WER work expanding), pre-emptive promotion saves later work.

For tools (SCTK, dscore, MedCAT, GitHub repos), promotion is a stylistic choice rather than a correctness one — they don't make claims that need verification, just point at infrastructure.
