# v4.2 Formal Definition triage — review file

**Purpose:** scaffold for reviewing the 18 🔴 + 1 🟠 metrics surfaced in Pass B before Phase 3 fixes land. One section per affected metric. For each, I've named the issue, the source-of-truth from the Pass B cache, and my proposed fix shape.

**How to use this file:**

- For each metric, write **`ok`** (proceed with proposed fix), **`revisit`** (something is wrong with my verdict or proposed fix — see the note), or freeform notes.
- The Pass B cache files at `reference-docs/v4.2-pass-b/` (gitignored) have the verbatim source quotes if you want to spot-check.
- Anything not marked is treated as "wait for review" — Phase 3 fixes only land on metrics you've thumbed-up.

**Default fix pattern across all 🔴s:** keep the metric concept; remove confabulated specific numbers OR re-frame them as "proposed in v4.2 as starting points" inside a ⚠ Provenance prelude (the same pattern v3.x Tier 1 tightenings established); drop confabulated source attributions; preserve real source attributions that DO check out.

**Bundle ordering:** grouped by source paper so you can react to each bundle as a unit if that's faster than per-metric.
