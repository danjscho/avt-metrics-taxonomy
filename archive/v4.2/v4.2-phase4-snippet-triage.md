# v4.2 Phase 4 — code snippet triage

**Purpose:** verification of the 27 Python code snippets across the in-scope metrics. For each, check (a) whether the snippet implements the metric's Formal Definition, (b) whether the library API is plausibly current, (c) whether there are confabulation patterns (fake function signatures, wrong class names, fabricated repo paths).

**Scope:** all 27 Python snippets in TP/PI/HL/GV files. Per the v4.2 plan, snippet correctness is illustrative-quality, not runnable-test-suite quality — the bar is "doesn't actively mislead", not "production-ready".

**Triage categories:**
- **✓ Match** — snippet correctly illustrates the Formal Definition and uses plausible library APIs.
- **~ Rewording** — snippet is approximately right but could be clearer; doesn't mislead.
- **⚠ Issue** — snippet has a real problem (wrong API, wrong logic, would mislead an implementer).
- **🔴 Confabulation** — invented APIs, fake class names, fabricated repo structure.
