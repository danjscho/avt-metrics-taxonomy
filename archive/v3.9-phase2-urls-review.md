## How to annotate

Per entry, replace the `[ ]` with one of:

- `[✓]` — URL is correct, accept
- `[!] <new-url>` — URL is wrong, here's the right one
- `[?]` — uncertain, please re-research
- `[skip]` — drop the entry from the catalogue (handle name and inline citations get updated to plain prose or removed)
- `[handle: <new-handle>]` — keep entry but rename handle
- `[+desc]` — keep URL, but description / title needs amendment (paste correction)

Free-text after the action is welcome. Where I've supplied multiple alternatives, just paste the URL you want.

When done, ping me and I'll patch the catalogue, run audit, then run snapshot.py against the resolved set.
