# `archive/v4.6/` — naming note

The three `v4.6-threshold-*.md` files in this directory were the working-name research outputs that fed the **v5.0.0 structural threshold split** (Trigger Conditions sub-block + Threshold Reference page). The work was named "v4.6" during planning because the original assumption was a v4.6 release would land the structural split — in practice, the split landed as **v4.5.1** (research output) + **v5.0.0** (the structural change itself), and there is no v4.6 release.

The directory name and filenames keep the original v4.6 working-name rather than being renamed to match the actual release tags, because:

1. The files are the historical record of how the work was *named at the time*, not what shipped.
2. The decision rationale is documented in `archive/v5.0.3/v5.0.3-cadence-plan.md` (line 67) and the v4.5.1 / v5.0.0 CHANGELOG entries.
3. Renaming would break those documented cross-references.

If you're looking for the released artefacts:

- The threshold structural split shipped in [v5.0.0](../../CHANGELOG.md).
- The Phase 1 / 2a / 2b research outputs (this directory) shipped as the [v4.5.1 patch](../../CHANGELOG.md), framed as "v5.0-prep research output".
