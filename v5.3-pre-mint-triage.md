## Review process

Per `b+c+iii`:

- **Pass A (internal coherence)** — proposed ref-ID slot is free; tier matches the FTS-direct rationale; name is consistent with cluster grammar; `_gaps.md` source row provides enough scaffolding to write a body.
- **Pass B (external source verification)** — where the gap row cites a specific NHS / framework requirement, the citation is checked against a primary or near-primary source. Where the underlying requirement is published guidance accessible via NHS pages or DTAC documentation, Pass B is mandatory. Where it is a community-of-practice expectation without a single citable source, the metric is marked **Maturity: Proposed/Novel** and Pass B is recorded as "framework-aligned, no single primary source — Proposed/Novel framing acceptable".
- **Reviewer sign-off gate** — review verdict per metric below before any bodies land. Conditional items (4) flagged for explicit reviewer attention.
