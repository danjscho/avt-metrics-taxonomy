## Categories

| Symbol | Meaning | Action |
|--------|---------|--------|
| ✓ | Match | No action. |
| ~ | Rewording | Substance right; prose loose. Opportunistic fix. |
| ⚠ | Softening needed | Definition overclaims relative to source. **Mandatory fix.** |
| 🔴 | Actual problem | Definition contradicts source / wrong citation / wrong construct. **Mandatory fix.** |

Pass A is internal-coherence only (definition ↔ Reference Standard / Threshold Guidance / Source row). Pass B will fetch external sources for ⚠ / 🔴 metrics plus a sample of ✓s.
